
## Ancient subglacial precipitate microbiome code

This repository contains scripts attached to the preprint "Ancient metagenomics reveals subglacial microbiomes driven by oxygen availability", available [here](https://www.biorxiv.org/content/10.64898/2025.12.03.692186v1/).

To view the damage-coloured Krona plots, [click here](https://bdesanctis.github.io/subglacial-precipitates/kronas.html). If these are loading too slowly for you I recommend trying a different browser (Chrome seems to load them quickly).

The code folder contains the bash scripts used to process the metagenomics data, and an R script used to make the figures, the latter which runs on input files all available in the data folder.
